This project is meant to help me plan and organize my LinkedIn posts.

**Workflow:**  
- I start by doing my research and save my notes in a file named `{{topic}}.research.txt` inside the `research` folder.
- For each post, I generate two main files:
  - The outline and structure of the carousel (what each slide should contain) is created in `{{topic}}.carousel.md` in the `carousel` folder. This file **does not contain the full content of the slides, just the structure and main points.**
  - The accompanying text for the carousel—which summarizes the topic, provides engaging hooks, encourages readers to check the carousel, interact, and discusses the importance—is drafted in `{{topic}}.post.md` in the `post` folder.

**Post Format:**  
My LinkedIn posts always follow a carousel format, with the main content and details presented in the slides, and a separate text post to introduce and discuss the subject, spark curiosity, and drive engagement.

This workflow streamlines my process to produce high-quality, interactive LinkedIn content.
