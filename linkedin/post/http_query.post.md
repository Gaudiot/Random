After 16 YEARS, a new HTTP method was introduced. And it has come to help with a problem developers have faced for a long time.


We all know and love the GET method. It is great for simple resource retrieval, and with query parameters, it can even refine the results!
But it has some limitations. If we need to apply very detailed filters, the URL may not be able to hold all the required information.

As a workaround, most developers use POST to send all this information through the request body. But then we lose some benefits, such as being safe, idempotent, and cacheable.

That's where the new QUERY method jumps in. It works pretty much like GET, but it accepts a request body.

That doesn't mean you should replace all GET requests with QUERY. Take a look at the research I did to understand it a bit better!
